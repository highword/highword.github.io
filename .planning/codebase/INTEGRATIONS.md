# Integrations

## Deployment
- **GitHub Pages** — Static site hosted at `giyanwei.github.io`
- Deployment method: `hexo-deployer-git` pushes built files to remote repo's `main` branch
- Repository: `https://github.com/giyanwei/giyanwei.github.io.git`

## CI/CD
- **GitHub Dependabot** — Automated daily npm dependency updates
  - Config: `.github/dependabot.yml`
  - Ecosystem: npm
  - Open PR limit: 20

## Social
- **GitHub** profile link: `https://github.com/giyanwei`
- **Email**: `quasar21@t.shu.edu.cn`
- **Social Share** buttons via `social-share.js`

## Theme (Butterfly) Integrations Available
The Butterfly theme supports (not all enabled):
- Comment systems: Disqus, Gitalk, Twikoo, Giscus, Utterances, etc.
- Analytics: Google Analytics, Baidu Analytics
- Chat widgets: Crisp, Tidio, Messenger
- Music: APlayer
- Search: Local search, Algolia

## Assets
- Custom graphics stored at `source/graphics/`:
  - `favicon.jpg` — Site icon
  - `avatar.jpg` — Author avatar
  - `wallpaper.png` — Default banner image
